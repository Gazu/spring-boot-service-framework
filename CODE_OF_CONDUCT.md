# Code of Conduct

## Our Pledge

We are committed to making this project a respectful and welcoming environment
for everyone who wants to contribute.

## Expected Behavior

Contributors are expected to:

- communicate respectfully and professionally;
- give and receive feedback constructively;
- focus discussions on the code, design, documentation, and project goals;
- respect different experience levels and perspectives;
- help keep issues, discussions, and pull requests productive.

## Unacceptable Behavior

The following behavior is not acceptable:

- harassment, threats, insults, or personal attacks;
- discriminatory language or behavior;
- publishing private information without permission;
- repeated disruption of project discussions;
- hostile or disrespectful review comments.

## Project Standards

Contributions must follow the standards described in
[CONTRIBUTING.md](CONTRIBUTING.md), including:

- commit messages written in English;
- Conventional Commits format;
- respect for Semantic Versioning;
- Git tags for every released version.

## Enforcement

Project maintainers are responsible for clarifying and enforcing acceptable
behavior. Maintainers may edit, reject, or remove comments, commits, issues,
pull requests, or other contributions that do not follow this Code of Conduct.

Maintainers may also temporarily or permanently limit participation for
contributors who repeatedly violate these standards.

## Reporting

If you see behavior that violates this Code of Conduct, report it to the project
maintainers through a private channel when possible.

Reports should include relevant context, links, screenshots, or examples so the
maintainers can review the situation fairly.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull
requests, discussions, code reviews, documentation, and any other official
project communication channel.
